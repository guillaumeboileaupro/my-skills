# CV Evidence Tailoring

Improve relevance without inventing or inflating experience.

- Extract responsibilities, required skills, optional skills, domain context, and likely objections from the offer.
- Build an evidence matrix linking each claim to a role, project, result, tool, duration, or concrete deliverable.
- Distinguish used professionally, used personally, studied, familiar, and not demonstrated.
- Never add unsupported technologies, seniority, production scale, language fluency, cloud platforms, or management claims.
- Preserve factual distinctions between experiences and do not merge unrelated achievements.
- Prioritize the strongest matching evidence, measurable results, delivery, quality, data, integration, and management when supported.
- Keep the requested CV format and make only the requested content or layout changes.
- Track reviewer feedback precisely and do not reintroduce removed content without reason.

Run `python scripts/evidence_matrix.py evidence.json requirements.txt` to identify supported and unsupported requirements before drafting.
